# Facts

The factual reference for every project and job. Bullets on a page get reworded to fit a job
description; the facts here change only when the work itself changes. Every claim on a resume
must trace to an entry in this file. Add an entry, and have the user confirm it, before anything
new goes on a page. Confirmed means the entry only restates what the user told you in this
session, in their own words, or the user said yes to it as written; silence is not confirmation.
Anything the user mentioned that is not yet confirmed goes under the entry's Pending field,
never on a page. The entry format and the reasoning behind it are in the skill's
`references/facts.md`.
